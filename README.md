# Superstore Sales Analysis

## Project Overview

This project focuses on cleaning, preparing, and analysing the Sample Superstore sales dataset using SQL and MySQL.

The objective is to explore sales data, identify business trends, evaluate performance, and extract meaningful insights that can support data-driven decision-making.

This project demonstrates practical data analytics skills, particularly data cleaning, data transformation, SQL querying, and exploratory data analysis.

## Tools & Technologies

* MySQL – Database management and SQL queries.
* SQL – Data cleaning, transformation, and analysis.
* Visual Studio Code – Writing and managing SQL scripts.
* Git & GitHub – Version control and project documentation.

## Dataset

The project uses the Sample Superstore dataset, which contains sales transactions and information about customers, products, orders, and shipping.

## Project Workflow

### 1. Data Preparation

* Inspected the original dataset.
* Examined column structures and data types.
* Identified missing values, inconsistencies, and formatting issues.

### 2. Database Setup

* Created a MySQL database.
* Designed the required table structures.
* Imported the original CSV dataset into MySQL.

### 3. Data Cleaning & Transformation

* Inspected the imported data.
* Handled missing and invalid date values.
* Standardised date formats.
* Removed unwanted spaces from relevant text columns.
* Transformed the data into a structured format.
* Stored the cleaned data in a separate table.

### 4. Data Analysis

* Product and category performance.
* Customer segmentation.

* Shipping performance.
